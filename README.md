# Katharine Wells · Portfolio

This repository contains a static portfolio built from the supplied GIS portfolio template framework.

## Structure

- `index.html` — portfolio overview
- `projects.html` — project and media gallery
- `about.html` — education, experience, and skills
- `contact.html` — verified contact links
- `config.js` — portfolio profile and project metadata
- `components.js` — shared navigation and page components
- `styles.css` — responsive layout and styles
- `project-*.html` — selected work detail pages
- `assets/` — résumé and media assets
- `research-assets/` — original maps, posters, photos, and source manifest

No template ZIP is committed to the repository.

## Preview

Run `python3 -m http.server 4173` from the repository root, then open `http://127.0.0.1:4173`.

## Public-release check

The original posters, photos, maps, and résumé remain subject to publication approval. This rebuild does not add reconstructed maps or private source documents.
